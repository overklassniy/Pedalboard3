# docs/

Documentation for Pedalboard3.

## Contents

- `ARCHITECTURE.md` — codebase architecture, threading model, key patterns
- `BUILD.md` — detailed build instructions for Windows and Linux
- `USER_GUIDE.md` — end-user feature documentation
- `MIGRATION.md` — notes on porting from JUCE 1.x to JUCE 8.0.15

## Integration

These documents are the primary developer and user reference. The root
`README.md` links to them. `AGENTS.md` at the repo root contains build setup
quick reference and JUCE 8 API notes.
